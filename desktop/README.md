# WarpScout Desktop (Windows 10 / 11)

Десктопная версия **WarpScout** на базе общего ядра `:core` (WireGuard/AmneziaWG, автоподбор точек и профилей шума, проверки сайтов/DNS, списки `allow-domains`, Второй выход).

В отличие от Android-версии, здесь убрано всё мобильное (проверки LTE/модема, экран, экономия батареи) и добавлено то, что нужно на компьютере: системный трей, автозапуск с Windows, минималистичный главный экран «одна кнопка» и работа через нативный движок **AmneziaWG** для Windows.

## Как работает туннель

- **Подбор и проверки** выполняются общим ядром `:core` (`AutoTuner`, `WgProber`, `JunkLibrary`, `AllowListPlanner`, `DnsInspector`, `ResourceProber`).
- **Поднятие туннеля** выполняется через системную службу Windows **AmneziaWG** (`amneziawg.exe /installtunnelservice`) с живым контролем handshake и трафика через `awg.exe show <tunnel> dump`.
- **Автопоиск движка:** приложение автоматически находит `amneziawg.exe` и `awg.exe`:
  1. по пути, указанному в *Настройки → Движок туннеля*;
  2. в папке `bin/` рядом с `WarpScout.exe`;
  3. в стандартных каталогах установки (`C:\Program Files\AmneziaWG`, `%LOCALAPPDATA%\Programs\AmneziaWG`);
  4. в системном `PATH`;
  5. запасной вариант — стандартный WireGuard (`wireguard.exe`) для профиля без шума (`none`).
- **Второй выход (свой регион):** поднимается вторым одновременным туннелем (`warpscout_exit2`) только для IP, собранных через DoH по указанным доменам. IP самого VPS автоматически исключается из `AllowedIPs` основного туннеля, чтобы не возникало петли маршрутизации. Если второй сервер недоступен, трафик безопасно возвращается в WARP.

## Основные возможности

- **Одна кнопка на главном экране** — если конфига ещё нет, сама подберёт рабочую точку и подключится; если конфиг есть — сразу поднимет туннель.
- **Системный трей Windows** — сворачивание в трей, цветной индикатор статуса на иконке, быстрое Вкл/Выкл, смена точки, переключение Топ-3 конфигов и проверка сайтов прямо из меню трея.
- **Автопереключение (failover)** — до 6 точек подряд при отказе или зависании сессии.
- **Топ-3 лучших конфигов** — мгновенное переключение между тремя разными точками входа без повторного скана.
- **Проверки сайтов, DNS и скорости** — проверка реальной доступности ресурсов из-под туннеля, обнаружение подмены DNS (системный vs Cloudflare/Google DoH), определение региона выхода (`cdn-cgi/trace` + `ipinfo.io`) и замер скорости (`speed.cloudflare.com`).
- **Маршруты (Split-tunnel)** — Весь трафик, Пресет обхода РФ, Списки `allow-domains` (скачивание и сборка через DoH), Вручную CIDR.
- **Экспорт / Импорт / Резервная копия** — AmneziaWG, WireGuard, Clash YAML, Routes, а также полный JSON-бекап настроек и ключей.

## Запуск и сборка из исходников

Требуется JDK 17:

```bash
# Запуск из исходников
./gradlew :desktop:run

# Тесты десктопного модуля и ядра
./gradlew :cli:selftest :desktop:test

# Портативная сборка Windows (WarpScout.exe + встроенный JRE, запускать на Windows)
./gradlew :desktop:createDistributable

# Установщик Windows .msi (запускать на Windows с WiX Toolset)
./gradlew :desktop:packageMsi
```

Готовые сборки (`WarpScout-<версия>-windows-x64.msi` и `WarpScout-<версия>-windows-x64-portable.zip`) автоматически собираются в GitHub Actions (workflow `desktop-windows`).

### Портативный режим

По умолчанию настройки, ключи и журналы хранятся в `%APPDATA%\WarpScout`. Если создать пустой файл `portable.txt` рядом с `WarpScout.exe`, все данные будут храниться локально в папке `data/`.
