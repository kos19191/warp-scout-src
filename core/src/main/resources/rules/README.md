# Списки доменов и подсетей (снапшот allow-domains)

Эти файлы — **вшитая копия** списков из [haritos90/allow-domains](https://github.com/haritos90/allow-domains)
(форк [itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains), лицензия MIT).
Приложение их не скачивает в рантайме: APK и CLI работают офлайн, а свежесть списков определяется
датой коммита, которая впечатана в `RuleCatalog.SNAPSHOT_DATE` / `RuleCatalog.SNAPSHOT_COMMIT`.

## Что лежит в файлах

| Имя | Что внутри |
|---|---|
| `<id>.v4.lst` | IPv4-подсети категории в CIDR, схлопнутые в минимальный набор |
| `<id>.v6.lst` | то же для IPv6 |
| `<id>.domains.lst` | домены категории — для DoH-резолва и проверок доступности |
| `union.v4.lst`, `union.v6.lst` | объединение всех подсетей апстрима (режим «только заблокированное в РФ») |

Категории — это папки апстрима `Categories/NN-*.lst` и `Subnets/{IPv4,IPv6}/NN-*.lst`. Разделение
по «чья сторона блокирует» задано в `RuleCatalog.Kind`:

* `RU_BLOCKED` — ресурс режут в РФ, поднятый туннель обязан его открыть;
* `BLOCKS_RU` — ресурс сам закрыт для РФ/дата-центров (например, `adr.it`): его недоступность
  **не** портит балл кандидата;
* `INFRA` — служебные диапазоны (хостинги, корпоративные сети) — туннелировать по желанию.

Сейчас подсети есть только у 8 категорий из 21. Остальные (YouTube, OpenAI, Claude, Discord-домены
и т.п.) — это списки доменов: в режиме «только выбранные категории» их адреса резолвятся через DoH
в момент генерации и добавляются как `/32`-маршруты (`SplitTunnel.build(extraCidrs = …)`), потому что
`AllowedIPs` в WireGuard умеет только IP.

## Как обновить

```bash
# 1. Забрать актуальный апстрим (или указать локальную копию через --source)
curl -L -o /tmp/ad.tar.gz https://codeload.github.com/haritos90/allow-domains/tar.gz/refs/heads/main

# 2. Пересобрать снапшот: .lst рядом, RuleCatalog.kt перегенерируется целиком
python3 tools/gen_rules.py --tarball /tmp/ad.tar.gz

# 3. Проверить, что ничего не потерялось, и закоммитить
git diff --stat core/src/main/resources/rules core/src/main/kotlin/dev/warpscout/core/presets/RuleCatalog.kt
./gradlew :core:selftest        # секция «списки allow-domains и split-tunnel» стережёт целостность
```

Скрипт идемпотентен, схлопывает подсети и **не** теряет адреса: сумма размеров сетей до и после
объединения сверяется внутри (см. `--max-prefixes`, по умолчанию 4000 на файл).

Обновлять стоит раз в 1–2 месяца: апстрим пересобирается еженедельно, но категории меняются
медленно. Дата снапшота видна пользователю в диалоге выбора категорий — так он понимает, насколько
списки свежие.
