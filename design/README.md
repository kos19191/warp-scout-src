# Макеты дизайна

Живые макеты экранов в браузере — по ним рисуется приложение. Открыть: любой статический сервер в
папке макета, например

```
python3 -m http.server 8090 --directory design/mockup
```

и в браузере `http://localhost:8090`. Слева — панель: дизайн, цвет (у «Нежного» и «Стекла»), тема,
экран (упрощённый, «Маршрут», расширенный), состояние туннеля (выключен, подбор, подключение, работает, нет связи) и «Проиграть
сценарий». Справа — телефон шириной 412 dp, как Samsung Note 20 Ultra.

| Дизайн | Где |
|---|---|
| **Премиум** — тёмный, оранжевое свечение, неоновое кольцо со щитом | в приложении с 1.10.49-beta7 (по умолчанию) |
| **Классический** — прежний вид | в приложении |
| **Нежный** — светлая пастель, акварельные пятна и волны, круглые карточки; 6 цветов: лаванда, мята, персик, небо, роза, ваниль | макет |
| **Стекло** — матовое стекло поверх неонового света, кольцо из двух неоновых цветов; 5 сочетаний: киберпанк, аврора, закат, ультрафиолет, кислота | макет |

Выбор дизайна, цвета и темы запоминается в браузере. Адрес вида `#design=soft&tone=2&theme=light`
открывает нужный вид сразу (`design`: `premium`, `soft`, `glass`; `tone` — номер цвета с нуля;
`theme`: `system`, `light`, `dark`).

- `index.html`, `style.css` — экраны и стили «Премиума»; `designs.css` — облик «Нежного» и «Стекла»,
  `designs.js` — их цвета;
- `ring.js` — кнопка-кольцо (подбор, подключение, вспышка щита), `map.js` — схема маршрута,
  `bg.js` — фон, `app.js` — панель и сценарий;
- `fox.png` — знак приложения;
- `fonts/` — Roboto и Roboto Mono (пакеты @fontsource 5.3.0), SIL Open Font License 1.1 — тексты
  лицензий рядом, `OFL-Roboto.txt` и `OFL-RobotoMono.txt`.
