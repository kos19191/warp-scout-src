# Макеты дизайна

Живые макеты экранов в браузере — по ним рисуется приложение. В телефоне макета всё нажимается:
круглая кнопка включает и выключает, стрелка-круг в шапке запускает подбор, карточка маршрута
открывает схему, карточки внизу — шторки, тумблер — расширенный режим с вкладками.

Открыть — сервер из этой папки, у каждого дизайна свой адрес:

```
python3 design/serve.py                              # http://localhost:8090 — «Премиум»
python3 design/serve.py --design soft  --port 8091   # http://localhost:8091 — «Нежный»
python3 design/serve.py --design glass --port 8092   # http://localhost:8092 — «Стекло»
```

Подойдёт и любой статический сервер в `design/mockup` (`python3 -m http.server 8090 --directory
design/mockup`) — тогда нужный дизайн выбирается панелью или адресом вида
`#design=soft&tone=2&theme=light` (`design`: `premium`, `soft`, `glass`; `tone` — номер цвета с нуля;
`theme`: `system`, `light`, `dark`).

В широком окне слева панель: дизайн, цвет (у «Нежного» и «Стекла»), тема, экран (упрощённый,
«Маршрут», расширенный), состояние туннеля (выключен, подбор, подключение, работает, нет связи) и
«Сценарий» — подбор, подключение и анимация «подключено» подряд. Справа — телефон шириной 412 dp, как
Samsung Note 20 Ultra. В узком окне (телефон, превью сбоку) сверху полоса: дизайн, тема и кружки
цветов, а вся панель — по кнопке «Ещё». Дизайн, цвет и тему можно сменить и в самом телефоне макета:
«Расширенный режим» → «Настройки» → «Оформление».

| Дизайн | Где |
|---|---|
| **Премиум** — тёмный, оранжевое свечение, неоновое кольцо со щитом | в приложении с 1.10.49 (по умолчанию; в бете — с beta7) |
| **Классический** — прежний вид | в приложении |
| **Нежный** — светлая пастель, акварельные пятна и волны, круглые карточки; 6 цветов: лаванда, мята, персик, небо, роза, ваниль | в приложении с 1.10.49 (в бете — с beta8) |
| **Стекло** — матовое стекло поверх неонового света, кольцо из двух неоновых цветов; 5 сочетаний: киберпанк, аврора, закат, ультрафиолет, кислота | в приложении с 1.10.49 (в бете — с beta8) |

Как это выглядит — `preview-soft-glass.jpg`. Цвет и тема запоминаются в браузере; дизайн — тоже,
но адрес сервера с `--design` всегда открывается в своём.

- `serve.py` — сервер макета: свой дизайн на каждом адресе, без кэша;
- `index.html`, `style.css` — экраны и стили «Премиума»; `designs.css` — облик «Нежного» и «Стекла»
  и полоса для узкого окна, `designs.js` — их цвета;
- `ring.js` — кнопка-кольцо (подбор, подключение, вспышка щита), `map.js` — схема маршрута,
  `bg.js` — фон, `app.js` — панель и сценарий;
- `fox.png` — знак приложения;
- цвета «Нежного» и «Стекла» в приложении выводятся из тех же исходных цветов скриптом
  `tools/design_palettes.py` (пишет `colors_designs.xml` и `themes_designs.xml`);
- `fonts/` — Roboto и Roboto Mono (пакеты @fontsource 5.3.0), SIL Open Font License 1.1 — тексты
  лицензий рядом, `OFL-Roboto.txt` и `OFL-RobotoMono.txt`.
